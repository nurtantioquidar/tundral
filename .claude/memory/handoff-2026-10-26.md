## Gotchas

- Commits are signed by 1Password; when signing fails, ask the user to unlock — never bypass.
  No AI trailers; single-line subjects with an action verb.
- Never print keys; read them with `op read` at run time. The auto-mode classifier refuses writing
  keys to disk and loosening Codex's sandbox — don't work around it, ask.
- Codex `exec -s read-only` blocks network, localhost and unix sockets for the agent's shell, so
  networked CLI features can't be benchmarked there (and won't work for Codex users).
- Bench/LLM runs go through `codex exec` (ChatGPT login), not paid keys; stop cleanly on quota.
- Install tools via `~/.config/nix` (`nix/home/home.nix`); gitleaks is now on PATH. Run it before
  pushing new history. The revoked ccode.dev key remains in history `84c10ef..96d0177~`.
- Clean room: never read Graphify source/prompts; only run its binary on scratch copies.
- CI: Rust test binaries need debug info off (disk); Linux inotify reports reads (fixed in watch).
- Piping `cargo clippy … | grep` hides its exit code — check exit status explicitly.
- Apple `container` on this Mac: the host DNS is Cloudflare WARP's loopback proxy, which the
  VM gateway cannot reach, so builds fail to resolve. Start the builder with
  `container builder start --dns 1.1.1.1 --dns 1.0.0.1` (default cpus/memory, or `container
  build` recreates it without the DNS). Named volumes are root-owned ext4 (chown once for a
  non-root image). Opossum resolves `build.dockerfile` against the Compose file's directory:
  use a local, git-excluded `compose.opossum.yaml` with an absolute path.
