Started 2026-10-12. Dijkstral (named after Dijkstra) is a Rust clone of Graphify (Graphify-Labs/graphify, PyPI `graphifyy`, baseline pinned at 0.9.86) that must be faster and more accurate and is benchmarked head-to-head against it.

User decisions (AskUserQuestion, 2026-10-12): lives in Monet at `products/dijkstral/` (cli Cargo workspace + bench/); v1 = **full parity including the LLM semantic pass**; benchmark axes = build speed+RSS, query latency, graph accuracy (SCIP oracle), agent task outcome — "everything that exists in Graphify".

Plan: staged 0–7 (scaffold+Graphify baseline → code core 5 langs → accuracy/Leiden/report → query/MCP/hooks → all langs+exporters → semantic pass → PR/hooks/installs → paid agent bench), stop for user review after each stage. Plan file: ~/.claude/plans/nifty-swinging-brooks.md.

**Why:** user wants "better and faster" than Graphify, language doesn't matter.
**How to apply:** clean-room — copy Graphify's formats (graph.json schema v1, ids.py recipe, exit codes, MCP tool names) but never its source, prompts or skill text. Paid bench runs only when the user triggers them. Do not import Butterfly's atlas crate (sibling product); reimplement. See [[butterfly-product]], [[monet-product-line-structure]].
