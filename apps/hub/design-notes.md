# monet.sh design notes

What was tried for the hub, and the owner's exact reactions. Read before any hub design session.

## 2026-10-08

- Tried: dark terminal page (shared @monet/ui tokens, amber accent), heading + five identical cards.
  Reaction: "the landing page still shit".
- Tried: dark terminal system map (request path diagram, spec table, amber accent, "Then, the canvas." section).
  Reaction: "still slop, I dont like the yellow thingy, please design better more art, provide the artsy logo for every tools".
- Process feedback: "dont use that hallmark shit" — no Hallmark skill, stamps, or scorecards.
- Context the owner gave: "monet is related with art and I wanna build art thingy connected with AI".
  Products: Inver (LLM gateway), Butterfly (harness), Cocoon ("1password for AI"), Nimble (fast AI router), Cicada (token ledger).

Rejected so far: amber/yellow accent, terminal-dark look, uniform card grids, diagram-as-hero.
Wanted: more art, a distinct artistic mark (logo) per tool, Monet-the-painter connection.

- Interview: references = "painting or artist" (no specific work named).
- Shown three hero mockups (throwaway HTML): A "Water Lilies" (linen canvas, pond palette, generated
  brushstroke pond), B "Impression, Sunrise" (misty dusk, one red sun), C "Woodblock" (cool paper,
  Prussian blue, red モネ seal). Each with Butterfly + Cocoon marks in that style. Awaiting pick.
- Owner picked B: "I choose B, idk how to insert AI or tech nuance here."
  Built and deployed: self-painting hero (strokes in reading order, "the way a model writes"),
  seed label + "Paint another", painted tool marks with one red region each, Cormorant + Geist.
  Awaiting reaction.
- Reaction to B build: "drop tio@monet.sh top right and footer, seems trash, I dont see any
  combination with tech AI thingy need to find that". Then the reference: "I like Anthropic when they
  introduce Fable" (anthropic.com/claude-fable-and-mythos-5-1: sky gradient hero, staggered serif
  title, [n] dotted-leader contents, "Made with Fable 5.1" corner credit, serif reading column).
  Rebuilt the hub on that frame with the painting as the sky. Awaiting reaction.
- Reaction to the Fable-framed version: "please redesign, idk it feels shit. I wanna have a modern
  pixel art for this" with a reference screenshot ("Quiet Place": sage sky, pixel pines and clouds,
  pond, rabbit fishing, mono type, coral pills). Rebuilt as a pixel Giverny: pines, lily pads,
  Monet's bridge, and a robot painting a sunrise at an easel; pixel icons per tool. Awaiting reaction.
- Reaction to pixel version: "nice this is better". Asked to remove "Drawn in code with Claude" and
  find a better logo. Shown five pixel logos: 1 water lily, 2 beret bot (robot head in a coral
  beret), 3 palette with brush, 4 bridge "m" (two footbridge arches under a coral sun), 5 Impression
  sun. Owner picked 1, the water lily.
